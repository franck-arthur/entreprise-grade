# Correction de l'erreur de schéma Audit

## Problème identifié

L'application ne démarrait pas à cause d'erreurs de validation de schéma Hibernate :
- Table `audit_events_command` manquante (erreur de nommage)
- Colonnes manquantes dans les tables d'audit

## Corrections apportées

### 1. Correction des noms de tables dans les entités JPA

**Fichier**: `backend/src/main/java/com/enterprise/app/domain/model/AuditEventCommand.java`
- Changé `@Table(name = "audit_events_command")` → `@Table(name = "audit_event_commands")`

**Fichier**: `backend/src/main/java/com/enterprise/app/domain/model/AuditEventProjection.java`
- Changé `@Table(name = "audit_events_projection")` → `@Table(name = "audit_event_projections")`

### 2. Correction des types de données

Dans les deux entités d'audit :
- Changé `UUID id` → `Long id` pour correspondre au schéma SQL (`BIGINT`)
- Changé `UUID userId` → `Long userId`
- Changé `UUID targetEntityId` → `String targetEntityId`
- Supprimé les imports `java.util.UUID` inutilisés

### 3. Correction du schéma SQL

**Fichier**: `backend/src/main/resources/db/migration/V001__Initial_Schema.sql`

Mise à jour de la table `audit_event_commands` pour correspondre aux entités JPA :
```sql
CREATE TABLE audit_event_commands (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    event_type VARCHAR(50) NOT NULL,
    user_id BIGINT,
    username VARCHAR(50),
    target_entity_type VARCHAR(100),
    target_entity_id VARCHAR(255),
    ip_address VARCHAR(45),
    user_agent VARCHAR(500),
    details TEXT,
    success BOOLEAN NOT NULL DEFAULT TRUE,
    error_message TEXT,
    timestamp TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

Mise à jour de la table `audit_event_projections` :
```sql
CREATE TABLE audit_event_projections (
    id BIGINT PRIMARY KEY,
    event_type VARCHAR(50) NOT NULL,
    event_category VARCHAR(50),
    user_id BIGINT,
    username VARCHAR(50),
    target_entity_type VARCHAR(100),
    target_entity_id VARCHAR(255),
    target_entity_name VARCHAR(200),
    ip_address VARCHAR(45),
    user_agent VARCHAR(500),
    details TEXT,
    success BOOLEAN NOT NULL,
    error_message TEXT,
    timestamp TIMESTAMP NOT NULL,
    event_date DATE,
    event_hour INTEGER
);
```

## Résultat

Les erreurs de schéma sont maintenant corrigées et l'application devrait pouvoir démarrer correctement.
